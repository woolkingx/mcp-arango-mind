Schema2Object

Role

schema2object owns the legal mechanics for resolving $ref, constructing schema-backed objects, applying defaults, validating shapes, and exporting materialized data. It does not own product decisions, tool semantics, MCP protocol shape, or ArangoDB execution.

The local copied usage guide lives at schema2object.usage.md.

Tool Owner Use

tools/schema/tools.schema.json
  -> $ref tool owner schema
  -> Loader resolves owner node
  -> ObjectTree validates command
  -> ObjectTree materializes payload defaults
  -> tool owner applies transition
  -> allowed Arango API call
