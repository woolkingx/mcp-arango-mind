Summary

mcp-arango-mind is a schema-driven MCP server for ArangoDB. The durable topology is MCP interface to surface root to tool owners to ArangoDB API owner. Custom behavior enters as tool owners, not as hidden protocol or Arango API logic.

The current runtime exposes mcp.mcp, mcp.help, mcp.arango, mcp.tool.template, mcp.tool.atlas, and the five mcp.tool.* API categories (database, collection, view, graph, admin). The target surface split into metadata, schema-owned help, raw OpenAPI, and direct category actions keeps large API and custom catalogs from becoming oversized action lists.

Usage Entry

node server.mjs
node server.mjs --sse --port 8000
npm test

Public quickstart stays in README.md. This handbook owns architecture, boundaries, gates, and migration shape.
