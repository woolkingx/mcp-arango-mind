Interfaces

Principle

MCP is the interface service access point. It projects existing owners to clients; it does not own tool payload truth, ArangoDB API data, environment data, config data, or custom transitions.

Entrypoints

EntrypointRoleBoundary
server.mjsCLI assembly and transport choice.Passes config to core.
src/transports/stdio.mjsMCP stdio transport.Calls core.handle(message).
src/transports/sse.mjsHTTP JSON transport with legacy flag name.Does not own protocol semantics.
src/protocol.mjsJSON-RPC validation and routing.Routes to tools/resources only.
src/mcp.mjsMCP schema reference and protocol version.Checks official MCP schema capabilities.

Pure Interface Rule

correct:
  MCP call -> MCP API shape -> tool owner boundary -> owner operator -> projection out

wrong:
  MCP handler decides tool truth
  MCP handler mutates config without naming the config owner
  OpenAPI schema stores tool transitions
