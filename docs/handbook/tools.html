Owner Contract

  -> $ref tool owner schema
     -> tool id
     -> actions
     -> object payload shape
     -> effect and evidence metadata
     -> allowed ArangoDB API operation ids

Runtime Path

tools/list
  -> resolve reachable tool schemas
  -> project MCP Tool list

tools/call
  -> validate { action, payload }
  -> resolve action operationId or custom handler
  -> project payload to the owned executor
  -> format result
